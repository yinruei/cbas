# 可轉債營收動能儀表板

台灣上櫃轉（交）換公司債清單，對照標的個股近 12 個月營收趨勢的互動式儀表板。

**Live**: https://yinruei.github.io/cbas/

## 內容

- `index.html` — 單頁應用（無外部相依，字型取自 Google Fonts）
- `data/bonds.json` — 386 檔公開發行可轉債（櫃買中心 OpenAPI `bond_ISSBD5_data`，已排除私募）
- `data/monthly_revenue.json` — 上市＋上櫃 1,856 家公司近 12 個月營收，含去年同月值（公開資訊觀測站 `t21sc03` 月報表）

## 指標定義

- **滾動 12 月年增**：近 12 個月營收合計 vs 去年同期合計，壓掉單月與季節雜訊
- **連續成長**：最近一段年增率連續為正（負）的月數
- **動能**：近 3 月年增均值 − 近 12 月年增均值（轉強／持平／轉弱）

顏色採台股慣例紅漲綠跌，並通過色覺辨認檢測（deutan ΔE 20.1）；漲跌一律同時標示 ▲▼ 與正負號。
